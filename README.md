# Portfolio

A sleek and responsive personal portfolio website built with HTML, CSS, and JavaScript — designed to highlight creativity, technical skills, and modern web development practices.

## 🚀 Features

- Smooth scrolling navigation
- Animated floating profile image
- Fully responsive design
- Clean dark theme with glowing accents
- Skills section showcasing technical expertise
- Footer with social media links

## 🛠️ Built With

- HTML5 — semantic and accessible structure
- CSS3 — animations, gradients, and responsive layout
- JavaScript (ES6) — interactivity and smooth scrolling
- Font Awesome — icons for skills and social links

## 💡 Usage

Clone the repository and open the project in your browser:

```bash
git clone https://github.com/TJ-Abel/Portfolio.git
cd Portfolio
open index.html
```

## 🌐 Deploying to GitHub Pages

You can easily host this portfolio online using GitHub Pages:

1. Push your project to a new GitHub repository.
2. Go to your repository’s Settings → Pages.
3. Under Source, select the main branch and the / (root) folder.
4. Click Save — your portfolio will be live in a few minutes.
